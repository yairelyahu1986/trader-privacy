# Privacy Policy

Last updated: 28 October 2026

## This is a private, personal application

This application is built and used only by its owner, Yair Huszcza, for his own
personal use. It is **not a public product** and **no one else is meant to use
it**. It is not offered, distributed or supported for any other person or
organisation, and no one other than the owner is asked to sign in to it or to
grant it access to anything.

## What the application accesses

With the owner's own permission, the application reads email in one Gmail
mailbox that belongs to the owner. It uses read-only IMAP access. It does not
send, delete or change any email.

## What the application does with the data

- It reads incoming email in order to find company announcements.
- The text of each email is sent to an AI service (Anthropic's Claude) so that
  the application can judge whether a message is a market-relevant announcement.
- The results are stored in databases that run on the owner's own
  infrastructure.

## What the application does not do

- It does not sell or rent any data.
- It does not share data with advertisers or any other third party, apart from
  the AI service named above, which receives email text only for the purpose of
  analysing it.
- It does not publish any data.
- It does not collect data about any person other than what appears in the
  owner's own mailbox.

## Retention and access

Data is kept only on the owner's own systems and is deleted when the owner
chooses to delete it. The owner can withdraw the application's access to the
Gmail account at any time at https://myaccount.google.com/permissions.

## Changes

If this policy changes, the date above will be updated.
